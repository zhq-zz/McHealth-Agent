## 一、项目简介

**McHealth Agent（麦麦饮食智能管家）** 是一个基于**麦当劳 MCP（Model Context Protocol）**开发的 AI Skill，
面向**减脂 / 控糖 / 食物过敏**人群，提供"**营养配餐 + 过敏原筛查**"的差异化解决方案。

区别于市面上大量"热量计算器"式选题，本项目聚焦**食品安全红线**：
在帮用户算热量的同时，**先过滤掉含过敏原的餐品**，让智能推荐真正"吃得起、吃得安全"。

用户只需用一句自然语言表达需求（例如"我想控制在 500 大卡以内、30 元以内，对花生和牛奶过敏"），
程序即可自动：

1. 调用麦当劳 MCP 拉取餐品、营养、过敏原与价格数据；
2. 按**过敏原黑名单**剔除风险餐品；
3. 在**热量上限 + 预算上限**双重约束下筛选可行组合；
4. 输出**营养报表 + 预算统计 + 过敏预警**三合一结构化结果。

## 二、核心功能

| 功能模块 | 说明 |
| --- | --- |
| 🥗 营养配餐 | 根据用户设定的热量上限，从麦当劳菜单中推荐合规餐品组合 |
| 🧪 过敏原筛查 | 支持用户输入过敏原黑名单（如花生、牛奶、麸质、鸡蛋、大豆），自动过滤风险餐品 |
| 💰 预算统计 | 按用户预算上限筛选，并输出总价、剩余预算、单价明细 |
| 📊 营养报表 | 汇总热量 / 蛋白质 / 脂肪 / 碳水 / 钠等关键营养素 |
| ⚠️ 过敏预警 | 对高风险餐品给出显式告警，避免误食 |
| 🗣️ 自然语言交互 | 命令行直接解析中文需求，无需记忆参数格式 |

## 三、快速启动

### 1. 环境要求

- Python 3.9 及以上
- 可访问麦当劳 MCP 服务的网络环境
- 已申请到的麦当劳 MCP Token（参赛者需自行申请）

### 2. 安装依赖

```bash
# 建议使用虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. 配置 MCP 密钥

复制配置模板为本地配置（**该文件已被 .gitignore 忽略，不会上传**）：

```bash
cp mcp-config.example.json mcp-config.json
```

然后编辑 `mcp-config.json`，填入你申请到的真实 Token：

```json
{
  "mcp_server_url": "https://your-mcd-mcp-endpoint",
  "token": "在这里填入你的真实Token",
  "timeout": 10
}
```

> ⚠️ **安全红线**：`mcp-config.json` 含真实密钥，严禁提交到 GitHub。
> 仓库只保留不含真实 Token 的 `mcp-config.example.json`。

### 4. 运行 Demo

```bash
python src/main.py
```

按提示输入你的需求即可。

## 八、注意事项

1. **密钥安全**：真实 Token 只允许写入本地 `mcp-config.json`；该文件已被 `.gitignore` 屏蔽。
   提交前请务必执行 `git status` 确认未包含密钥文件。
2. **数据来源**：餐品、价格、营养数据均通过标准 MCP 协议从麦当劳 MCP 服务实时获取，
   项目本身不硬编码业务数据。营养匹配采用**方案B**：
   先用 `query-meal-detail` 把套餐**拆解成子单品**，再按子单品名匹配营养表，
   实测营养命中率由 **19/115 提升到 82/115**，解决了"大量餐品热量为 0"的问题。
   ⚠️ **重要限制**：实测麦当劳 MCP（35 个工具）**未提供「过敏原」数据源**，
   因此过敏原筛查目前只能依赖模拟数据（`--mock`）、名称守卫兜底，
   或后续自建的本地对照表。详见 `MCP_INTEGRATION.md` 第三节第 4 条。
   在真实模式下若需查看推荐效果，可显式使用 `--allergen-policy warn`
   （默认 `strict`：过敏原未知即剔除，结果会为空）。
3. **过敏原免责**：本工具结果基于数据做筛查，**不能替代医生的专业诊断**。
   严重过敏用户请以门店实际配料表与官方说明为准。
4. **MVP 边界**：本项目当前只实现核心 MVP。
   「多人合餐模式」「活动优惠券自动匹配」作为**可选扩展**，未纳入主代码，以保证交付稳定性。
5. **合规**：本项目仅用于大赛 Demo 演示，未用于任何商业用途。
